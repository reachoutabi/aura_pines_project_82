Aura Pines HTML5 Template Documentation

1. Template Overview

AURA PINES is a production-ready, ThemeForest and TemplateMonster standard HTML5 template engineered specifically for luxury campgrounds, glamping resorts, trekking base camps, and eco-retreats.

It features the bespoke Midnight Pine & Ember design palette, complete dual Dark and Light modes, GPU-accelerated 60fps Ken Burns moving hero background animations across all pages, native RTL bidirectional layout compatibility, a 5-step interactive frontend booking engine, and a full-featured Guest Portal Dashboard.

3. Customizing Colors & Tokens

All colors and design tokens are defined in assets/css/variables.css. You can customize the entire theme by modifying the CSS variables: 

/* Dark Mode Tokens (assets/css/variables.css) */
[data-theme="dark"] {
  --bg-app: #0B1612;               /* Midnight Pine */
  --bg-surface: #12221B;           /* Deep Spruce */
  --bg-elevated: #1A2E25;          /* Forest Shadow */
  --accent-primary: #D2824A;       /* Ember Copper */
  --accent-hover: #E39A5E;         /* Burnished Amber */
  --accent-secondary: #4F8F8A;     /* Glacier Teal */
  --text-primary: #EFE7D6;         /* Moonstone Sand */
  --text-muted: #A9B8A0;           /* Lichen Sage */
}

/* Light Mode Tokens */
[data-theme="light"] {
  --bg-app: #F6F1E7;               /* Warm Parchment */
  --bg-surface: #FFFBF3;           /* Linen */
  --accent-primary: #B9662F;       /* Ember Copper (AA contrast) */
  --accent-secondary: #2F6F6B;     /* Glacier Teal */
  --text-primary: #12261D;         /* Deep Pine */
}

4. Centralized Images Config

To make photo maintenance effortless, all high-resolution photography URLs are organized in assets/js/images-config.js. To replace with your client's local images, simply point the dictionary keys to your local files in assets/images/: 

const CAMP_IMAGES = {
  hero: {
    main: "assets/images/hero-campsite.jpg",
    secondary: "assets/images/glamping-dome.jpg"
  },
  stays: {
    glampingDome: "assets/images/stays/dome.jpg",
    safariTent: "assets/images/stays/safari.jpg"
  }
};

5. LocalStorage Architecture

assets/js/store.js provides seamless demo persistence across page reloads:

  • User Profile: Demo credentials guest@campwild.com / Guest@123.
  • Reservations: Seeded bookings plus all newly created reservations from booking.html.
  • Wishlist: Favorited stays and activities saved with live heart icons.
  • Packing Checklist: Interactive checkboxes synced live.
  • Itinerary: Drag and re-orderable day schedules.
  • Reset Demo Data: Available anytime in Settings inside the Guest Dashboard.

6. RTL & Multilingual Setup

The template uses modern CSS logical properties (margin-inline, padding-inline, inset-inline). Activating RTL layout simply sets dir="rtl" on the root <html> element, which is toggled via the navbar toggle button and saved to LocalStorage.
